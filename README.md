# 5-Stage-Pipelined-RISC-V-Processor
A 32-bit RISC-V pipelined processor implemented in SystemVerilog using a 5-stage pipeline (IF, ID, EX, MEM, WB). Designed and verified using AMD Xilinx Vivado 2022.2, with testbenches covering instruction execution, forwarding, hazards, branch handling, load/store operations, and reset behavior.
